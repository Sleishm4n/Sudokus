# Sudokus

A collection of Sudoku solvers written in multiple programming languages

## Overview

Repo contains implementations of Sudoku solving algorithms in various languages. The goal is to have different sudoku solving algorithms implemented in different languages, currently only using the basic backtracking algorithm. 

**Languages currently included:**
- Python ( array indexing and NumPy)
- Java
- C (array indexing and pointer arithmetic)
- Rust
- C++

Each version solves the standard 9×9 Sudoku puzzle.

---

## Future

In the future, I hope to implement other algorithms, such as:
- Stochastic Search / Optimisation methods
  - Simulated Annealing
  - Genetic Algorithm
  - Tabu Search

I also aim to implement different types of Sudokus:
- Samurai Sudokus
  - Collection of 5 intertwining Sudokus
- Super Duko
  - A 16x16 grid that uses hexadecimal
